Experimental estimate

STL estimates credited interception on the selected pass, or the highest-valued available pass when none is selected. BLK estimates a credited block if the holder shoots from current geometry. Each model has five defenders plus no event summing to 100%; do not add these different scenarios. Trained on observed actions, not validated forced actions. PASS · catch EPV / TO

Definitions

Green rings: discounted pass EPV above the current EPV, with no defender able to reach the direct route under our timing assumptions. Ballhandler: current EPV from the selected model. Attached nodes: SHOT is expected field-goal points plus miss-weighted second-chance points (assuming a live miss, excluding free throws); PASS is the highest available turnover-discounted pass value. These are experimental estimates, not validated action rankings. Teammates: expected points after turnover discount / pass TO %. Select a teammate to preview the catch. Dashed gold outlines show projected positions. Amber teammate rings flag direct routes already within a defender’s reach.

Definitions

Approximate scenarios, not a validated best-action ranking. TO% is fitted to selected passes of mixed types, not a forced straight-line pass. Ambiguous failed-pass destinations are excluded from training; — means this projection is unavailable. Pass values always use the shooting-aware EPV model.

What followed similar dribble starts—not which moves this player could execute optimally. Each branch is the first event on the same touch. A pass includes subsequent pass turnovers; a shot includes its associated foul. Neither is counted again in the separate turnover/foul branches.

Definitions

Trained on first dribbles of a touch; applying this forecast later in a dribble sequence is an extrapolation. Movement and defender closing speed are inputs. No defender reaction policy or named-move availability is established. SHOT above is immediate-release value; PASS projects a catch; this panel describes subsequent behavior and is not added to either value.
